# Sales & Business Performance Dashboard

## 📊 Project Overview

This project is an interactive Power BI dashboard created to analyze sales and business performance for 2025.

The dashboard provides a clear view of sales trends, profitability, regional performance, category performance, and top-selling products.

## 🎯 Project Objectives

- Analyze overall sales and profit
- Track monthly sales trends
- Compare sales performance across regions
- Analyze sales by product category
- Identify the top 5 products by sales
- Provide interactive filtering using Region and Category

## 🛠️ Tools & Technologies

- Power BI
- DAX
- Power Query
- Microsoft Excel

## 📈 Dashboard Features

- Total Sales KPI
- Total Profit KPI
- Total Orders KPI
- Average Order Value
- Monthly Sales Trend
- Sales by Category
- Sales by Region
- Top 5 Products by Sales
- Region and Category dropdown filters

## 💡 Key Skills Demonstrated

- Data cleaning and transformation
- Data analysis
- DAX measures
- Interactive dashboard design
- Data visualization
- Business performance analysis
